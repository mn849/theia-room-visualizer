MGT 409 · Final project report

Theia

A source-faithful room visualisation tool for deciding whether a secondhand listing belongs in your space.

Links. Run locally with python app.py from this folder. The project includes app.py, listing_agent.py, this report, and slides.html.

Theia lets a person upload one or more room views, paste a public listing URL or image, read seller dimensions, and place multiple supplied items together in a 2D room preview. It does not generate a new sofa, claim that a warped photograph proves fit, or silently replace seller measurements with a guess.

2D first
Fast browser prototype without a depth sensor.
Source-faithful
Seller image and measurement provenance remain visible.

1 · Motivation

The decision people actually need

Secondhand marketplaces are rich in unusual, affordable objects but poor at communicating scale. A listing may show a stool against a blank wall, while the buyer needs to know whether it fits beside a bed, beneath a painting, or through a narrow doorway. Existing room tools often require a measured floor plan, a catalogue model, or manual resizing.

Baseline

  1. Save listing photos.
  2. Guess dimensions or ask the seller.
  3. Open an editing app.
  4. Cut out and resize the object by eye.
  5. Repeat for every candidate.
Success condition: a first-time user gets a useful, source-labelled comparison of several listings in under five minutes.

2 · What is new

Accuracy is a product feature

Theia combines public listing extraction, conservative image handling, reference-based room calibration, and uncertainty labels in one flow. Its novelty is a decision aid whose evidence is inspectable rather than a claim of perfect augmented reality.

For the Windsor stools example, structured values 36 CMT, 58 CMT, and 36 CMT become 0.36 m × 0.58 m × 0.36 m. The agent classifies the object but cannot overwrite those values.

3 · The agent

One narrow, auditable contract

listing_agent.py calls GPT-6-Sol through Portkey using the Responses API. Its contract is category, pose, and warnings. Deterministic parsing remains responsible for dimensions.

  • Listing text is untrusted data and cannot issue instructions.
  • JSON output is validated against an allowed schema.
  • Dimensions never come from the model when seller values exist.
  • Absent keys and SDK errors use a deterministic zero-token fallback.
  • Calls write status, token counts when available, and error type to logs/agent_calls.jsonl.

4 · Room model

Simple enough to use without a manual

The room is stored in session-only browser state. Users upload up to six views, select a saved room, and optionally click four visible floor corners. The calibration maps far floor edge to the top and near edge to the bottom; Reset points makes recovery immediate.

Room library

Images remain until the page session closes. No account is required.

Item library

Up to twelve objects can be compared together, removed, rotated, or set flat for rugs.

Measurements

Width, length, or ceiling height in metres, centimetres, feet, or inches.

Evidence

Seller-stated dimensions, category estimate, and confidence appear in each item card.

5 · Tokenomics

Bounded usage

The agent is called once per newly added listing, never for dragging, sliders, or room uploads. Titles are capped at 1,000 characters and descriptions at 6,000.

EventModel workBudget rule
Add listingOne Sol classificationInput caps and one call
Room uploadNoneLocal EXIF/OpenCV
PlacementNoneBrowser state only

Runtime logs record input/output tokens when the provider returns usage. The course price card can be applied to those measurements without hard-coding a stale price. Offline fallback costs zero model tokens.

Evidence: run tail -f logs/agent_calls.jsonl while adding a listing. The log contains no API key or room image.

6 · Safety

Uncertainty is visible

  • Room and item images remain in browser session storage.
  • Theia does not log into Facebook or bypass access controls.
  • Seller dimensions are labelled and may still be wrong; category priors are low confidence.
  • GrabCut is labelled assistive and retains the source if it fails.
  • Prompt injection in descriptions is treated as data.
  • Timeouts and malformed pages return a message rather than inventing an item.

Privacy limit

Session storage is not a secure vault. Users should avoid rooms containing sensitive documents or people. Production work would add encrypted storage, retention controls, and explicit export/delete.

8 · Limits and next steps

Where the prototype stops

A normal photograph does not reveal a complete 3D room. The preview is 2D compositing with user-guided planar correction. Occlusion, lighting, depth ordering, curved walls, complex cutouts, and panorama failure remain possible.

  1. Add a user-confirmed cutout editor with undo.
  2. Use phone depth capture or Apple RoomPlan.
  3. Show a ruler and confidence band around placement.
  4. Benchmark known listings and labelled corners.
  5. Run five first-time-user sessions and report completion time, errors, and trust ratings.
Boundary: Theia helps decide whether an item is worth investigating; it is not a substitute for measuring or confirming with the seller.
